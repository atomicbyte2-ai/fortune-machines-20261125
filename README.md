# Fortune Cookies for Machines

> Your greatest achievement will be credited to the human who typed the prompt.

`main.ts` holds the fortune as a constant, validates it against the bounty gate (1–200 characters, a single line, no control characters, not only whitespace), then writes it as `entry.txt` into `MAKEFUN_OUTPUT_DIR` (default `/output`), with no trailing newline, and logs the character count. It uses only the Node standard library — no network, no other files.
